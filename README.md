## Como utilizar o programa
Clone ou baixe os arquivos do repositório.

Abra o seu emulador do terminal de preferência e navegue até a pasta raiz do projeto baixado.

Utilize o comando abaixo para restaurar as depedências do projeto.

```
dotnet restore
```

Em seguida compile e execute o projeto com o comando:

```
dotnet run --project Calculadora.Consoleapp
```
